# 自訂粵語詞表 —— 開會時發現翻錯的詞就加在這裡，下次啟動生效。
#
# 格式：粵語<TAB>普通話        （中間用 Tab 鍵分隔，不是空白）
# 井號開頭的行是註解，空行會被忽略。
# 這裡的條目優先於內建詞表，所以也可以用來「修正」內建的翻譯。
#
# 注意：不接受單字規則（除了粵語專用字），因為單字替換很容易誤傷普通話。
#       例如「平」→「便宜」會把「水平」變成「水便宜」。
#       要翻單字請改成兩字以上的詞，像「好平」→「很便宜」。
#
# 範例（把井號拿掉就生效）：
# 落定	付訂金
# 齋講	光說不做
# 蛇王	偷懶

# --- 你的客戶 / 產品專有名詞 ---------------------------------------------
# 公司名、人名、產品型號如果常被辨識錯，可以在這裡強制修正。
# 例如辨識老是把「宏達」聽成「紅大」：
# 紅大	宏達
